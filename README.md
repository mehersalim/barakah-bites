## ✨ Features

- 🍔 **Responsive Design** — Looks perfect on desktop, tablet, and mobile
- 🔥 **Dynamic Menu Tabs** — Filter menu items by category (Burgers, Chicken, Sides)
- ⭐ **Customer Reviews Section** — Showcase Google Reviews and testimonials
- 📍 **Google Maps Integration** — Embedded location with "Get Directions" link
- 🕌 **Halal-Certified Branding** — Authentic Middle Eastern-inspired design
- 🎨 **Custom Animations** — Smooth scroll reveals, marquee ticker, hover effects
- 📞 **Click-to-Call Button** — One-tap calling for mobile users
- 🎯 **SEO-Friendly Structure** — Semantic HTML, optimized meta tags
